# OIML SMART Style Guide

This repository holds the writing style guide for the OIML SMART program. The guide governs all public-facing content produced under the program, including the CNML certificate format, the OIML-CS SMART platform, and related documentation.

## Contents

- `WRITING_STYLE.md` is the canonical style guide. It defines register, prohibited patterns, content rules, vocabulary, formatting, and editorial workflow.
- `CLAUDE.md` directs Claude Code agents working in any OIML SMART repository to read and apply the style guide.
- `AGENTS.md` is the framework-neutral equivalent for any AI agent framework.

## How to consume

OIML SMART repositories that publish written content should reference this guide from their own contributing documentation or root-level agent files. A typical reference takes the form: writing for the repository follows the OIML SMART style guide at https://github.com/oimlsmart/styleguide/blob/main/WRITING_STYLE.md, and the guide is read before drafting documentation, README sections, FAQ entries, or any other prose intended for publication.

## Status

The initial version of this guide was distilled from editorial review of the CNML certificate format documentation. It is expected to evolve as the OIML SMART program publishes additional content types.
